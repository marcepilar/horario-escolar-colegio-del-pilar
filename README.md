# Horario Escolar — Colegio del Pilar (DEMO NO OFICIAL)

Versión de prueba V1.0.3 para demostraciones comerciales de MARK-TECH SOFTWARE.

**Esta aplicación no está vinculada oficialmente con el Colegio del Pilar y sus horarios son ficticios.** La identidad gráfica institucional se utiliza exclusivamente como recurso ilustrativo de la propuesta.

## GitHub Pages

Configuración: **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**. El sitio necesita HTTPS para instalarse como PWA.

Esta PWA incluye `manifest.webmanifest`, `service-worker.js`, `version.json` e iconos de instalación. Todos los recursos usan rutas relativas.

No coloques los archivos dentro de una subcarpeta al subirlos: `index.html` debe quedar en la raíz.
